## Sobre o projeto Manager Lounge

A narguile sempre foi algo presente em minha vida e na cultura de muitas pessoas ao redor do mundo 
e por isso resolvi criar um projeto simples usando este tema para servir de estudo.
O próximo passo seria a criação dos testes e um possível front-end usando Angular e talvez Bootstrap.
